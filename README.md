# L2L (Luv to Life)

야외 활동 시 조도(Lux), 날씨, 사용자 특성을 바탕으로 자외선 위험도와 권장 활동 시간을 안내하고, 건강 미션·식물 성장·친구 기능으로 실천을 돕는 웹 프로토타입입니다.

## 현재 상태

| 구분 | 상태 | 내용 |
| --- | --- | --- |
| 웹 화면 | 진행 중 | 단일 페이지 대시보드와 반응형 UI가 구현되어 있습니다. |
| 위험도 계산 | 구현됨 | UV, 운동 시간/강도, 피부 타입, 나이, BMI, 성별을 조합합니다. |
| 브라우저 저장 | 구현됨 | 사용자 설정 및 친구 데이터가 `localStorage`에 저장됩니다. |
| 미션·정원 | 구현됨 | 4개 미션을 모두 완료하면 70 GC를 받고 새 미션 세트가 자동 시작되며, 도감은 누적 미션 완료 횟수로 해금됩니다. |
| 센서 로그 수집 | 구현됨 | Python 스크립트가 시리얼 센서 데이터를 텍스트 로그로 기록합니다. |
| 센서와 웹 연동 | 구현됨 | 앱이 2초마다 최신 센서 값을 받아 조도·온도·습도를 갱신합니다. |
| 문구 인코딩 | 점검 필요 | 일부 한글 문자열이 깨져 표시되어 파일 인코딩 정리가 필요합니다. |

## 빠른 실행

별도의 빌드 도구는 필요하지 않습니다. 센서 연동을 처음 실행할 때만 `pyserial` 설치가 필요합니다.

1. 센서 수집과 웹 서버를 함께 실행합니다.

   ```powershell
   pip install pyserial
   python "import serial.py"
   ```

2. 브라우저에서 `http://127.0.0.1:8000/index.html`을 엽니다.

센서 연동에는 반드시 위 Python 서버를 사용해야 합니다. `python -m http.server`로 실행하면 화면은 열리지만 센서 API는 제공되지 않습니다.

## 센서 로그 수집

`import serial.py`는 `COM3`, `115200` baud의 시리얼 장치에서 `[온도,습도,조도]` 형식의 패킷을 읽어 `wireless_sensor_log.txt`에 추가 기록하고, `http://127.0.0.1:8000/api/sensor`로 최신 값을 제공합니다. 센서가 일시적으로 끊겨도 서버는 종료되지 않고 3초 간격으로 재연결을 시도합니다.

```powershell
pip install pyserial
python "import serial.py"
```

장치 연결 환경에 맞게 스크립트 상단의 `PORT`, `BAUD_RATE`를 수정해야 할 수 있습니다. 종료는 `Ctrl+C`입니다.

## 프로젝트 구조

```text
.
├── index.html                 # UI, 화면 상태, 이벤트 처리
├── src/utils/                 # 계산 및 브라우저 저장 기능
│   ├── calculate*.js          # UV, BMI, 위험도, 권장 시간, 식물 상태 계산
│   ├── get*.js                # 피부/나이/BMI/성별/운동/UV 보정 계수
│   ├── applyMissionBonus.js   # 미션 완료에 따른 위험도 보정
│   ├── friendSystem.js        # localStorage 기반 친구 기능
│   └── userStorage.js         # 사용자 데이터 저장/불러오기
├── import serial.py           # 시리얼 센서 로그 수집기
└── wireless_sensor_log.txt    # 수집된 센서 로그
```

## 주요 계산 흐름

1. 조도를 UV 지수로 환산합니다. (`Lux / 2000`, 최대 11)
2. UV·운동 시간·사용자 보정 계수를 곱해 위험 점수를 계산합니다.
3. 자외선 차단, 물 마시기, 그늘 휴식 등 완료 미션을 위험도에 반영합니다.
4. 위험도와 누적 UV로 권장 활동 시간을 표시합니다.

> 이 계산은 현재 프로토타입용 경험적 규칙입니다. 의료적 판단이나 전문 진단을 대신하지 않습니다.

## 데이터 저장

웹 앱 데이터는 서버로 전송되지 않으며, 브라우저의 `localStorage`에 저장됩니다.

- 사용자 정보: `sun-care-user-data`
- 친구/응원/물주기 기록: `sun-care-friends`

브라우저 저장소를 삭제하면 해당 데이터도 초기화됩니다.
